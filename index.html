acra-SecretsScanner

A command-line tool that scans source code files for exposed secrets like API keys, passwords, and private keys. It uses regular expressions to identify potential secrets, and reports a Shannon entropy value (bits per character) for each found value.

Open the repo Usage

The value itself never appears

Found values are masked in every report, console and file alike: the report shows the key name, line, length of the mask, and entropy, never the value itself. A secret can be named, located, and measured without ever being printed.

Usage

./acra-secretsscanner [params]
-hShow help message and exit
-oPath to the file to save the scan results

How it reads

The scanner searches source code files with regular expressions for the shapes of exposed secrets, API keys, passwords, and private keys among them. For each found value it computes a Shannon entropy value in bits per character, so a report carries both where the secret sits and how strong it looks, while the secret itself stays under the bar.

The honest limits

The README documents no scan target argument and no sample output, so neither appears here. What the README does document is the masking rule above, and it holds in every report the tool writes.
