Secrets Left Exposed

acra-SecretsScanner is a command line tool that scans source code files for exposed secrets. The three kinds it hunts:

API keys

Passwords

Private keys

It identifies potential secrets with regular expressions.

Masked in Every Report

For each found value the report gives a Shannon entropy value in bits per character.

Found values are masked in every report, console and file alike. A reader sees the key name, the line, the length of the mask, and the entropy, and never the value itself.

The Value Itself Never Appears

Masking is the heart of this tool: the report shows where a secret lies and how strong it looks, while the secret stays where it was found, unseen by anyone reading the report.

At the Gate

Install is a single clone line, as the README gives it:

git clone https://github.com/ShadowStrikeHQ/acra-secretsscanner

Usage is given exactly as documented:

./acra-secretsscanner [params]

Honestly stated: the README names no scan target argument, shows no worked example of a file or folder being scanned, and lists no patterns, so a visitor cannot learn those things here, because the source document does not state them.

The Two Parameters

-h shows the help message and exits.

-o takes the path to a file where scan results are saved.

Those two are the complete documented set.

A Short Honest Closing

The README for this project is thin. It gives no sample output, no exit code behaviour, no list of file types covered, and no test results. This page states that absence in plain words instead of inventing a fuller tool.
